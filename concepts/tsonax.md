## 개요
- **목적:** 실시간 주식 데이터 수집 → 차트 분석 → 시각화
- **기술 스택:** C# (.NET), 실시간 데이터 파이프라인
- **개발 브랜치:** `feat/minichart-tf-series-reconnect` (https://github.com/eekek74/TSonaX/tree/feat/minichart-tf-series-reconnect)
- **상태:** `[TSonaX] 1차 배포` 업무는 **2026-09-29 12:39 완료 처리 확인**(DB `status=완료`, `closed_at` 실측) → 배포 마일스톤 #2 종료

## 주요 기능
- **미니차트 TF 시리즈:** 타임프레임별 차트 데이터 재연결 처리
- **실시간 데이터:** WebSocket 기반 실시간 시세 수신
- **분석 지표:** 이동평균, 볼린저밴드, RSI 등
