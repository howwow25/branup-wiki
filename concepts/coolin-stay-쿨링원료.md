# COOLIN stay — 쿨링·항열노화 원료 (LABIO 제안)

> 라비오(LABIO)가 브랜업에 제안한 천연유래 복합 냉감 원료. 열(heat)에 의한 피부 노화를 억제하고, 즉각적·지속적 쿨링을 제공하는 듀얼 메커니즘 소재.

---

## 핵심 컨셉

**열 자극은 차단하고, 쿨링은 오래 지속하는 이중 메커니즘 쿨링 솔루션**

| 항목 | 내용 |
|------|------|
| **정의** | TRPV1·TRPM8 channel 이중 조절로 열에 의한 피부 스트레스 완화 + 즉각적·지속적 쿨링 원료 |
| **성상** | 투명한 액체 |
| **효능** | 열노화 방지, 즉각적·지속적 냉감 효과 |
| **사용** | 스킨케어, 바디케어, 두피케어 |
| **권장 함유량** | 3.0 ~ 5.0% |

---

## 작용 메커니즘 (Dual TRP Sensor)

### STEP 1 — 열노화 억제 (TRPV1 inhibition)
- 열 자극에 의한 자극·붉어짐·열스트레스 완화, 피부 탄력 감소 억제
- 핵심 성분: **다발방패버섯발효물 (Albatrellus Confluens Ferment)** — 항산화·항염·TRPV1 활성억제·손상세포 재생·수분증가

### STEP 2 — 쿨링 지속 (TRPM8 activation)
- 냉각감각수용체(TRPM8) 활성으로 즉각적 쿨링·진정·자극완화
- 핵심 성분: **ML (Menthyl Lactate), MGA (Menthone Glycerin Acetal)** — 저자극 안전성 확보 쿨링제
- **에리스리톨 (Erythritol)** — 자연유래 저분자 폴리올, 흡열(Endothermicity)로 즉각적+지속적 쿨링

---

## INCI 성분

```
2,3-Butanediol, Saccharomyces Ferment Filtrate, Erythritol,
Albatrellus Confluens (Mushroom) Extract, Menthyl Lactate,
Menthone Glycerin Acetal, 1,2-Hexanediol
```

---

## 시험 데이터 (제안서 내 포함)

| 시험 | 결과 |
|------|------|
| **In-vitro MMP-1 억제** | 45℃ 열자극 조건에서 농도 의존적 MMP-1 감소, HSP(HSP70/HSP27) 발현 1·3시간 시점 억제 |
| **TRPV1 활성억제 (Ca²⁺ influx)** | 45℃ 열자극 2시간까지 TRPV1 활성 최대 29.8% 억제 |
| **쿨링 지속력 (전완 In-house)** | 3% 적용 시 무도포 대비 10분까지 쿨링 지속, 0.3% 멘톨 대비 3~5분 이상 지속 |
| **피부 일차자극** | 피부반응도 0.00 / 피부자극지수 0.00 (비자극, 피부과 전문의 평가) |
| **두피 쿨링 임상** | 42명 대상(20~60세), 쿨링 지속력 2시간 이상, 멘톨 대비 쿨링 강도 2배 (KC 피부임상연구센터) |
| **안면 쿨링 In-house** | 5명 대상, 20분 이상 쿨링 지속 |

---

## 안전성

- **ML, MGA:** JECFA(FAO/WHO 합동 식품첨가물 전문가위원회) 평가에서 현재 사용 수준 안전성 우려 없음
- **EWG:** ML·MGA 모두 Green 등급(1~2), Menthol(3등급)보다 안전성 높음

---

## 적용 검토 포인트

- 아이젤 브랜드 기존 라비오 원료 3% 적용과 별개로, **쿨링·열노화(Heat Aging) 기능성 제품** 개발 시 후보 소재
- 열노화(Heat Aging) — 반복적 고온 자극으로 콜라겐 분해·산화스트레스 촉진되는 노화 개념. 하절기·홍조·민감성 소비자 타겟
- 두피케어 적용 가능 (두피 쿨링 임상 데이터 보유)
